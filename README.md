# llins — Product builder

A portfolio shaped around public projects and experiments by [@llinsss](https://github.com/llinsss).

## Live site

[llinsss-portfolio.llinsomoudu.chatgpt.site](https://llinsss-portfolio.llinsomoudu.chatgpt.site)

## Source

The static portfolio lives in [dist/index.html](dist/index.html). It uses HTML, CSS, and browser JavaScript with no package install or build step. The page includes a scroll-reactive laptop scene, project cards linked to GitHub, responsive sections, and small local interactions.

To preview locally:

```sh
python3 -m http.server 8000 -d dist
```

Then open http://localhost:8000.
